Minecraft Dev — its UI surface in OpenIDEA mockup · not a screenshot

The plugin has no plugin UI: OpenIDEA's sandbox has no webviews or dialogs, so the whole surface is (1) commands in Search Everywhere / the keymap, (2) notification balloons, and (3) the contributed theme + languages in Settings. Commands are also invokable with an argument, e.g. executeAction("plugin.minecraft-dev.insert-main","fabric").
